# Olympics-Data-Analysis

## Datasets

1. **athletes**: Contains information about all the athletes who participated in the Olympics.
2. **athlete_events**: Contains information about all the events that happened over the years. The `athlete_id` in this table refers to the `id` column in the `athletes` table.

## Questions

 Problem 1: Which team has won the maximum gold medals over the years?

- Find the team that has won the maximum number of gold medals across all Olympic years.

 Problem 2: For each team, print total silver medals and the year in which they won the maximum silver medal. Output 3 columns: `team`, `total_silver_medals`, `year_of_max_silver`.

- Calculate the total number of silver medals for each team and determine the year in which they won the maximum number of silver medals.

Problem 3: Which player has won the maximum gold medals among the players who have won only gold medals (never won silver or bronze) over the years?

- Identify the player who has won the most gold medals but has never won a silver or bronze medal in any Olympics.

Problem 4: In each year, which player has won the maximum gold medals? Print year, player name, and the number of golds won in that year. In case of a tie, print comma-separated player names.

- For each Olympic year, find the player(s) who won the most gold medals. In case of a tie, list the player names in a comma-separated format.

Problem 5: In which event and year did India win its first gold medal, first silver medal, and first bronze medal? Print 3 columns: `medal`, `year`, `sport`.

- Find the first event and year in which India won its first gold, silver, and bronze medals, respectively.

Problem 6: Find players who won gold medals in both the Summer and Winter Olympics.

- Identify the players who have won gold medals in both the Summer and Winter Olympics.

Problem 7: Find players who won gold, silver, and bronze medals in a single Olympic event. Print player name along with the year.

- Identify the players who have won gold, silver, and bronze medals in the same Olympic year and event. List the player names along with the year.

Problem 8: Find players who have won gold medals in three consecutive Summer Olympics in the same event. Consider only the Olympics from 2000 onwards. Assume the Summer Olympics happen every 4 years, starting in 2000. Print player name and event name.

- Find players who have won gold medals in the same event for three consecutive Summer Olympics, starting from the 2000 Olympics.
